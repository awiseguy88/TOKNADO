Hermes Agent + TOKNADO

How to use Hermes Agent with TOKNADO as a custom endpoint

Hermes Agent, the open-source agent from Nous Research, can run against a Nous Portal subscription, OpenRouter, or a custom endpoint that implements the OpenAI chat completions API. TOKNADO fits that last option, so you can run Hermes on a single endpoint and key.

Below are the three ways to point Hermes at TOKNADO (wizard, .env, config.yaml), how to confirm it works, and what to check when it doesn't.

What you need

  • Hermes Agent installed (the installer puts its files under ~/.hermes/).
  • Your TOKNADO endpoint and API key from the dashboard.
  • A model ID copied from your TOKNADO dashboard.

Setup: Hermes Agent with TOKNADO

  1. Option A: use the setup wizard

    Run the model setup and pick Custom endpoint (enter URL manually). Enter the TOKNADO base URL, your key, and the model name when prompted.

    hermes setup model

  2. Option B: set environment variables

    Hermes reads custom endpoint settings from ~/.hermes/.env.

    # ~/.hermes/.env
OPENAI_BASE_URL=https://toknado.up.railway.app/v1
OPENAI_API_KEY=YOUR_TOKNADO_API_KEY

  3. Option C: edit config.yaml

    Set the provider to custom and give it the base URL and default model in ~/.hermes/config.yaml. Keep the key in .env rather than the YAML.

    model:
  default: "toknado/auto"
  provider: "custom"
  base_url: "https://toknado.up.railway.app/v1"

  4. Start Hermes and send a test message

    Launch it and ask for something small. A reply means the endpoint, key and model are all correct.

    hermes
Some Hermes tools use OpenRouter separately. Hermes documents that features such as vision, web summarization and mixture-of-agents can call OpenRouter independently, even when your main model is a custom endpoint. If a side feature fails while chat works, that is where to look.

Notes for real-world use

  • Hermes is built for long-running, tool-heavy sessions, so it can consume requests quickly. Pick a plan whose rolling hourly limit matches how often you run it.
  • Use hermes config edit to change settings later, or re-run hermes setup model to switch models without reinstalling.
  • Don't commit ~/.hermes/.env or any file holding your key.

Troubleshooting Hermes Agent + TOKNADO

SymptomWhat to check
Wizard doesn't list your endpointChoose the custom/manual endpoint entry near the bottom of the provider list rather than a named provider.
401 or “invalid API key”Check OPENAI_API_KEY in ~/.hermes/.env holds the TOKNADO key, not an old OpenAI key.
404 or connection errorConfirm OPENAI_BASE_URL includes the API path (normally /v1) and has no trailing /chat/completions.
Model not foundThe default model in config.yaml must match a model ID from your dashboard exactly.
Chat works but a side tool failsThat feature may be calling OpenRouter on its own; set an OpenRouter key for it or skip the feature.

FAQ

Can Hermes Agent use a custom OpenAI-compatible API?

Yes. Hermes supports a custom endpoint configured with a base URL and key, for example via OPENAI_BASE_URL and OPENAI_API_KEY in ~/.hermes/.env.

Where does Hermes store its settings?

In ~/.hermes/: config.yaml for settings, .env for keys, and auth.json for OAuth credentials.

Do I need a Nous Portal subscription?

No. Nous Portal is one option; a custom endpoint like TOKNADO is another, and you can switch between them.

How do I switch back?

Run hermes setup model again and choose a different provider.
