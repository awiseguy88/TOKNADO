How every integration works

  1. Sign up, then copy your API key and endpoint from the dashboard.
  2. In your tool, choose its OpenAI-compatible / custom provider option.
  3. Paste the endpoint as the base URL, paste the key, and enter a model ID.
  4. Run the one-line curl check from the tool's page, then start working.

Setup guides

  • OpenClawAdd TOKNADO as a custom provider in the OpenClaw wizard or config.
  • Hermes AgentPoint Hermes Agent at a custom OpenAI-compatible endpoint.
  • Codex CLIDefine a custom model provider in ~/.codex/config.toml.
  • Claude CodeRun Claude Code through an Anthropic-format layer in front of TOKNADO.
  • OpenCodeAdd TOKNADO as a custom provider in opencode.json.
  • Open WebUIAdd TOKNADO as an OpenAI connection in Admin Settings.
  • DeepSeekUse DeepSeek-class models in OpenAI-compatible coding tools.
  • ClineUse Cline's OpenAI Compatible provider with TOKNADO.
  • AiderUse OPENAI_API_BASE and the openai/ model prefix.
  • Roo CodeUse Roo Code's OpenAI Compatible provider, per mode if you like.

Don't see your tool? If it accepts a custom OpenAI-compatible base URL and API key, the same three values apply. Read the general setup guide.
